- Локальный запуск через uv: Python 3.13.13, Django 5.2.18; главная страница и статические файлы доступны на порту 8000.

- Docker Compose `config --quiet`: успешно. Образ собран с `uv sync --locked --no-dev`; контейнер запущен через `compose up --build -d`.
- В контейнере Python 3.13.16, Django 5.2.18: `check` без ошибок, все 11 тестов прошли. Зависимости совпадают с локальными и закреплены в uv.lock.
- Пример curl из README проверен на опубликованном порту контейнера: HTTP 200, ожидаемый тестовый ответ, `sources: []`.
- Headless Chromium: основной сценарий и повторный вопрос прошли для uv и Docker. Проверены вопрос из пробелов без отправки запроса, ошибки сети и API, состояние ожидания и восстановление кнопки, сохранение вопроса и вывод ответа как текста. Ошибок JavaScript нет.
- Интерфейс проверен на ширине 1280 и 375 пикселей; горизонтальной прокрутки нет. Скриншоты просмотрены.
- `node --check` для JavaScript и `git diff --check`: успешно.
