# Приёмка КТ №2: интерфейс и основной сценарий RAG

Задача №14. Поведение описано в [scenarios.md](scenarios.md) и [product.md](product.md), решение — в [architecture.md](../tech/architecture.md).

## Выполнено автоматически (2026-11-20)

Окружение: Windows 11, uv 0.13.9 (`python -m uv`), Python 3.13 из lock-файла, Chromium Playwright 1.64.1, Docker Desktop (Engine 29.9.2). LLM заменена HTTP-заглушкой `tests/browser/llm_stub.py`: для uv она запущена отдельным процессом, для Compose — внутри контейнера.

| Проверка                                                                                          | Результат                                            |
| ------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `manage.py check` (uv и в контейнере)                                                             | Без ошибок                                           |
| `manage.py test tests` (uv и в контейнере)                                                        | 61 тест, OK; покрытие `app/` строк и ветвей — 94,71% |
| `docker compose up --build`                                                                       | Образ собран, контейнер запущен                      |
| `npm run test:browser` против uv                                                                  | 23 из 23                                             |
| `npm run test:browser` против Compose                                                             | 21 из 21                                             |
| Ruff check/format, djLint lint/check, ESLint, Prettier (`--end-of-line auto`), `git diff --check` | Успешно                                              |

Браузерные сценарии: главная без надписи о демо; примеры — подсказки без запроса; свободный вопрос; ответ с источниками (название, фрагмент, ссылка); отказ отдельным блоком без источников; замена прошлого состояния; пустой ввод; блокировка повторной отправки и сообщение о долгом ожидании; таймаут (лимит 90 с в тесте сокращён до 0,2 с); ошибки 403/502/503 с сообщением сервера и с запасным текстом; некорректный JSON, нет `refused`, неверный источник; сеть; HTML как текст; ширина 375 и 1280 px; один реальный проход `/ask` через BM25 с заглушкой.

После исправления обработки пустого тела при 502 и HTML при 503 все 23 сценария прошли через uv. Для Compose в таблице указан предыдущий прогон до этого исправления. Ерофей сверяет оценки ответов с разметкой Антона по тем же 15 ответам.

Ответы сервера в браузерных тестах подменяются через `page.route`, кроме последнего сценария. Эти проверки не доказывают качество ответов реальной LLM.
