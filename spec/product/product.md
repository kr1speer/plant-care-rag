# Продукт: «Зелёный помощник»

## Пользователь

Человек, у которого дома есть комнатные растения, но нет опыта ухода за ними.

## Задача пользователя

Быстро получить понятный ответ на конкретный вопрос об уходе за растением (полив, освещение, пересадка, удобрения, болезни и вредители) и иметь возможность проверить, откуда взят ответ.

## Целевое поведение после КТ №1 (план)

- Принимает вопрос на русском языке в свободной форме.
- Находит подходящие фрагменты справочных статей с помощью поиска BM25.
- Формирует ответ с помощью LLM только на основе найденных фрагментов.
- Показывает ответ и список источников (название статьи, фрагмент, ссылка).

## Демонстрация КТ №1

Согласованное решение: интерфейс и API запускаются в одном Django-проекте. Пользователь выбирает один из трёх примеров или вводит вопрос. Сервер возвращает подготовленный ответ только для поддерживаемого примера. Ответ содержит название статьи, точный фрагмент и ссылку из корпуса. Это демонстрация интерфейса и интеграции, а не поиск или генерация.

Примеры: мелкие листья монстеры без прорезей; температура для фикуса Бенджамина; пересадка фаленопсиса. Для других вопросов сообщается об ограничении демонстрации, без утверждения об отсутствии информации во всём корпусе. На странице явно указано, что BM25 и LLM не подключены.

Критерии и результаты приёмки: [КТ №1](kt1.md). До выполнения проверок согласованное поведение не считается подтверждённым.

## Границы продукта

- Не ставит диагноз по фото и не работает с изображениями.
- Не отвечает на вопросы вне темы ухода за комнатными растениями.
- Не придумывает ответ, если в базе статей ничего не нашлось, — сообщает об этом.
- Не хранит историю вопросов и не требует регистрации.
- Не заменяет консультацию специалиста при серьёзных проблемах с растением.
